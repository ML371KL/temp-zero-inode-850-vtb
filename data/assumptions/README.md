# Книга допущений Банка ВТБ

Единственный экземпляр книги допущений модели: ядро читает только машинную книгу `assumptions.yaml`
(`model/book.py`, закрытая схема `model/book_schema.py`, ключи — `docs/MODEL.md`, приложение A). Книгу меняет только
её новая версия; решает о ней владелец или ведущий. Версии помечаются тегами git `book-<версия>`
(`git show book-0.8:data/assumptions/assumptions.yaml`).

## Что здесь

| Файл | Что |
|---|---|
| `assumptions_template.yaml` | шаблон машинной книги — все ключи прил. A, кроме `worlds.<W>.*` и `worlds_bank.*`; **правят его**; решения ведущего — шапкой и комментариями у ключей |
| `build_assumptions.py` | сборщик: шаблон + миры семейства + банковская надстройка + хэши → `assumptions.yaml` и `assumptions.json`; `--check` — сборка воспроизводит файлы; функция `build()` |
| `assumptions.yaml`, `assumptions.json` | машинная книга — выход сборщика; руками не правится |
| `worlds_source.json`, `worlds_source.csv` | общая запись миров семейства — **побайтово** (`.gitattributes`: `worlds_source.* -text`) |
| `worlds_inputs.yaml`, `worlds_recipe.py`, `WORLDS-RECIPE.md` | рецепт миров книги-источника — обезличенные копии; `python -B data/assumptions/worlds_recipe.py --check` воспроизводит запись; кандидат новой записи миров у этой панели — `python -B ops/tools/refresh_worlds.py --record <каталог записи> --out <каталог>` (`docs/MANUAL.md` §10.5) |
| `worlds_bank.json` | банковская надстройка миров (рост кредитов по трём группам сектора, средств клиентов, номинального ВВП; 2026–2029) — собирает `evidence/worlds_bank/build_overlay.py`, хэш — в `worlds.overlay.sha256`; совпадает с надстройкой банков семейства бит в бит |
| `evidence/` | лист надстройки миров и лист вывода чисел на ядре `path/derive_on_engine.py` с приёмочными листами (`evidence/README.md`); листы калибровки — в папке передачи |
| `results.json`, `run_output.txt` | таблицы книги — выпуск ядра (`python -B -m model.book_results`), коммитит интеграция |
| `gate_explanations.yaml` | объяснения сработавших гейтов (MODEL §14.2) — эксплуатация, правится без новой версии книги; текст печатает витрина — словами для владельца |
| `release_notes.yaml` | записки о задуманных скачках заголовка (MODEL §14.4) — эксплуатация |

Текст книги (`ASSUMPTIONS-BOOK.md`: суждения, числа, оси, класс надёжности, обоснования с источниками) пишется после
машинной части; пока его нет, тесты текста книги пропускаются с названной причиной (`tests/test_book_texts.py`).
Первичные документы (отчётность, формы Банка России) в репозиторий не кладутся: в листах — хэши и выписки чисел со
ссылкой на документ и страницу; полные листы этапа 1 и первичка — в папке передачи (`$BANK_HANDOFF_DIR`).

## Порядок новой версии книги

Из корня репозитория, Python 3.12 (stdlib + PyYAML):

1. **Шаблон.** Правка `assumptions_template.yaml`; в шаблоне поднять `meta.version`. `meta.date` — дата книги: день
   цены, кривых и оценки (вместе с ней — `meta.valuation_date`, `meta.market_price` и зерно полосы). При
   перезаякоривании — `meta.facts_date`, `anchor_period`, `first_period` вместе с фактами `data/facts/`.
2. **Миры и надстройка.** Миры пересобираются только вместе с книгой-источником семейства: новая запись
   `worlds_source.json` (+ `.csv`) — побайтово, `worlds_recipe.py --check` обязан её воспроизводить. Надстройка —
   `python -B data/assumptions/evidence/worlds_bank/build_overlay.py`.
3. **Сборка.** `python -B data/assumptions/build_assumptions.py` — пишет `assumptions.yaml` и `assumptions.json`.
4. **Вывод чисел на ядре.** Ключи с пометкой «ВЫВОДИТСЯ НА ЯДРЕ» выводит одна команда —
   `python -B ops/tools/rederive.py` (сначала с `--dry-run`): подбор листа `evidence/path/derive_on_engine.py`, запись
   в шаблон («было → стало»), пересборка, быстрые числа и приёмочные проверки. После этого числа заморожены: в цене
   правила, справочных вариантах, прогонах полосы и обратном расчёте они не пересчитываются.
5. **Прогон ядра.** `python -B -m model.book_results --fast` — проба, затем полный `python -B -m model.book_results`
   (`results.json`, `run_output.txt`).
6. **Проверки.** `pytest --basetemp=var/pytest-book -p no:cacheprovider tests/test_book_*.py`, затем полный набор.
   Сработавшие гейты — записи в `gate_explanations.yaml`.
7. **Тег.** Коммит версии и тег `book-<версия>` на нём; тег не переносится — ошибка исправляется следующей версией.
