# Доказательные листы книги допущений

Числа книги, которые не взяты прямо из документа и не суждения, выводятся здесь — воспроизводимо, без сети, из корня
репозитория. Первичка (PDF, XLSX) в репозиторий не кладётся — только ссылкой, страницей и sha256 внутри листов. Ответы
брокерского API не кладутся вовсе — ни файлом, ни таблицей, ни выпиской полей.

Листы калибровки книги ВТБ (капитал, ЧПД, отчёт о прибыли, прочие доходы, экономические проверки кругов) — в папке
передачи (`$BANK_HANDOFF_DIR/stage1/calib-*`, `econ-check-*`); числа, которые читает лист вывода, лежат его входом
`path/inputs/vtb_r2_inputs.json`. В дереве — два листа.

| Область | Скрипты | Что даёт книге |
|---|---|---|
| `worlds_bank/` | `build_overlay.py` | надстройка миров `worlds_bank.json`: рост сектора по трём группам кредитов и средств клиентов (N — середины базового сценария Банка России; H, M — по инфляции мира; 2026–2029); файл совпадает с надстройкой семейства бит в бит |
| `path/` | `derive_on_engine.py` (с описанием `derive_spec.py` для команды перевывода книги), `marginal_loan.py`, `facts_check.py` | вывод на ядре чисел, которые следуют из суждений, фактов якоря и пути баланса клеток, и концов осей; проверки — предельная экономика роста на предельной единице модели и приёмочные проверки книги против фактов (`path/README.md`) |

Порядок пересчёта у новой версии книги: `worlds_bank` (при новой записи миров) → `python -B ops/tools/rederive.py`
(подбор листа `path/derive_on_engine.py`, запись в шаблон, пересборка, быстрые числа и приёмочные листы; сначала с
`--dry-run`). Проверки: `tests/test_book_worlds.py` (надстройка), `tests/test_book_evidence.py` (листы без ответов
брокерского API, лист вывода и лист предельной экономики роста на ядре дерева), `tests/test_book_template.py` и
`tests/test_ops_rederive.py` (запись вывода и книга).
