# Лист вывода на ядре — книга Банка ВТБ

Числа книги, которые не суждения, а следствия суждений, фактов якоря и пути баланса клеток, выводит лист
`derive_on_engine.py`; в шаблон книги их вписывает команда

```
python -B ops/tools/rederive.py                 # подбор → запись в шаблон («было → стало») → пересборка → быстрые числа → проверки
python -B ops/tools/rederive.py --dry-run       # весь путь на пробной книге, в дерево не пишется ничего
python -B ops/tools/rederive.py --centre-only   # пробный счёт решения: только центр, книга пробная
python -B ops/tools/rederive.py --no-derive     # быстрые числа и проверки на книге как есть
```

Что где лежит:

| Файл | Что |
|---|---|
| `derive_on_engine.py` | лист: шаги и их правила (суждения листов и решений — константами с источником) |
| `derive_spec.py` | описание для команды: фазы запуска, адрес каждого числа в шаблоне, точность записи, коридор разумного с пояснением, невязки правил, соотношения |
| `marginal_loan.py` | предельная единица роста: рубль корпоративного кредита НА ПРЕДЕЛЬНОЙ ЕДИНИЦЕ МОДЕЛИ (решение № 4, п. 3.7): несёт прочие активы без дохода, прочие обязательства и резерв, фондируется балансирующей статьёй ядра, капитал — Н20.0 (весь базовый, с путём вычета и растущим вычетом якоря); сверочная строка — разность ядра в модальной клетке при премии +1 п.п. (совпадение до 1 п.п.); прежние чтения — справочно |
| `facts_check.py` | приёмочные проверки книги: маржа года после якоря 1(а) — на режиме «нормализация» внутри окна C 2,6–3,2 %, смесь заголовка, модальная клетка и клетка окна рядом (решение № 6, п. 2.3); квартал с месячными фактами (все строки); сумма «ЧПД + прочие» против окон фактов — по ключу и по пути клеток; доля прочих доходов; путь клетки мира-опоры против бэктеста книг; предельный кредит мира H на базовом капитале; рост кредитов и RWA смеси и внешний капитал против фактов и арифметики листа капитала |
| `inputs/vtb_r2_inputs.json` | числа листов, которые лист читает, а не выводит: ближние ключи спредов книг (бэктест) и числа калибровки, которыми лист calib-nii их пишет (`nii_books.near_rule`: снятие остатка якоря 2027 года, решение № 7, п. 2.4), факты премии средств клиентов, RWA книг листа капитала, числа разбора прочих доходов, путь маржи бэктеста книг |
| `out/derive_out.json`, `.txt`, `derive_start.json` | запись вывода, давшего числа шаблона (пишет команда) |

## Шаги и порядок

| Шаг | Правило | Ключи книги |
|---|---|---|
| `bridge` | мост упр. ↔ движок фактов; мост маржи после выноса денег из книги ликвидности — около нуля | — (проверка) |
| `anchor` | RWA книг листа капитала к остаткам фактов; прочие активы — вес на часть, несущую риск; вычеты якоря — формулой; якорь воспроизводит RWA и оба норматива | `capital.rwa.density`, `capital.n20.deductions_anchor`, `capital.n11.gap_pp`, `volumes.other_assets_to_loans` и `volumes.other_assets_fixed` (числом: их ведёт ось доли вычета якоря), `capital.n20.deductions_fixed_share` и `capital.n11.deductions_fixed_share` (доля вычета якоря, постоянная в рублях, — узел фактов `balance.fixed_share_of_deductible`, одно число на оба норматива), концы оси-связки доли 0,4…0,8 (обе доли и сторона баланса той же раскладкой прочих активов) |
| `payout` | доля политики от всей прибыли ÷ (1 − доля меньшинства) | `dividends.policy.payout` |
| `issue` | выпуск по 87 ₽ одним местом (решение № 4, п. 3.1): приток квартала выпуска = доля денег × объём + распределения + возврат купона; делитель — объём / 87; концы связок осей объёма и доли денег и приток вариантов той же формой; «вложение по своей цене» — арифметикой | `equity.other_movements`, концы двух связок выпуска, приток 10 вариантов |
| `relief` | «послабление» после возврата надбавок (решение № 4, п. 3.4): доля возврата года × смесь трёх сценариев (0,30 / 0,45 / 0,25) по годам; прежняя форма — вариант; регуляторный вычет «послабления» — та же смесь той же долей возврата (решение № 5, п. 3.3; ключи пишет шаг `deductions`) | `capital.reg_scenarios.relief.{sifi,ccyb}`, вариант `relief_return_to_schedule` |
| `realized` | реализованная передача (решение № 5, п. 3.4): центр — произведение середин «измеренная (−0,068 / −0,023 / +0,022) × (1 − доля книги без процентного дохода, 0 / 0,5 / 1)» без округления (−0,0115); концы оси движка — так, что P10 и P90 оси, как её разыгрывает движок (положение — треугольник с модой 0, медиана у центра книги), равны P10 и P90 произведения двух независимых треугольников: конец = центр + (квантиль произведения − центр) / \|s(квантиль)\|; носитель произведения — диапазон строки обратного расчёта | `nii.transmission.target`, концы оси передачи |
| `near_spreads` | ближние ключи спредов книг — числа листа (бэктест книг на ключевой мира-опоры плюс остаток книги на якоре): сверка книги с записью | — (сверка) |
| `loans` | премии роста кредитов к сектору — уровень окна в мире окна (решение № 3, раздел 3): в 2027–2028 годах книги мира M растут темпом окна фактов (юрлица +10 %, физлица −5 %), далее премия линейно сходит к нулю к 2032 году | `volumes.loan_share_drift.*`, концы оси роста после 2028 года |
| `near` | общий ближний сдвиг маржи по MODEL §3.2 (решение № 5, п. 3.5): в квартале с месячными фактами клетка печатает маржу фактов (d); в 1-м квартале года σ0 — d и встречная σ0 (вклад σ0 в маржу модальной клетки), линейный сход к 2028 году (1 / 0,75 / 0,5 / 0,25); приёмка — ступень маржи 2027К1 − 2026К4 не больше ступени одних книг на ставках мира (печать обеих) | `regimes.near_nim_shift` |
| `misc` | ближний ключ прочих доходов 2027 года — пара к ближнему пути маржи; середина окна C (решения № 4, п. 3.6; № 5, п. 3.5): сумма «ЧПД + прочие» клетки «мир M × нормализация» в знаменателе окна разбора = середина окна C восьми месяцев (с результатом 100,8 и без); концы оси — края окна; варианты ближнего пути маржи (`no_near_shift`, `near_sigma0_step_kept`) — с ключом, выведенным парой к их пути (шаг `ends`); **2028–2029 годы (решение № 7, п. 2.4: пара к переходной части пути ЧПД сходит вместе с ней)** — прямая к LT от пары к пути центра без всех переходных частей 2027 года: встречная σ0, сдвиг d 2027 года (d года якоря остаётся), половина остатка якоря каждой книги с ключом года, остаток книги бумаг (тем же счётом, что пишет её ключи: путь бэктеста на ключевой мира H и обращение лага — разность ключей по кварталам при доле остатка 0,5 и 0), сход спреда опта (2027 год — LT); числа счёта книг — вход `nii_books.near_rule` (лист сначала повторяет ими ключи книги, иначе отказ); начало — ключ 2027 года минус разность пар (снятие накопительно, лист печатает пару каждой части и ЧПД 2028 года клетки окна в обеих формах — совпадает до второго порядка, допуск 5 млрд ₽); в полосе — оси ключа 2027 года и LT — связки и ведут ключи 2028–2029 годов долями прямой (2/3 и 1/3 приращения ключа, 1/3 и 2/3 приращения LT); то же у вариантов ближнего пути (пара к пути варианта без его переходных частей, шаг `ends`) и вариантов уровня (своё LT); форма книги 0.6 (минус одна пара к встречной σ0) — вариант `misc_near_pairs_inherited` | `other.misc_net_real.2027`, `.2028`, `.2029`, оси-связки ближнего года и LT (ключи прямой на концах), ключи 2027–2029 годов у вариантов `misc_lt_*`, ключи 2027–2029 вариантов ближнего пути, ключи 2028–2029 варианта `misc_near_pairs_inherited` |
| `level`, `splits` | уровень маржи равен ключу цели; доли раскладки — числа листа: полы спреда кредитных книг и потолок стоимости средств клиентов | — (проверки) |
| `funds` | премия роста средств клиентов — середина между фактами и «нуждой баланса» (кредиты к средствам клиентов модальной клетки на конец 2031 года — как на якоре); после 2028 года — тот же сход, что у премий кредитов | `volumes.funds_share_drift.*`, концы оси премии и оси роста после 2028 года, вариант `funds_premium_need` |
| `t2` | дополнительный капитал: плоско в рублях по квартал ступени, далее доля RWA модальной клетки; с ключом ядра `capital.n20.t2_share` (решение № 6, п. 2.1: с 2029Q1 каждая клетка держит долю своих RWA) траектория после 2028 года ядром не читается — это рубли модальной клетки, справочный вариант `t2_modal_rub` (ключ выключен) | `capital.n20.t2` |
| `deductions` | путь вычета сценария по природе слагаемых (решение № 3, п. 6.2) на ключах пятого прохода ядра (решение № 4, раздел 4, К1–К2; п. 3.2): суммы в рублях (доля η роста вычетов, высвобождение ОНА) — `deduction_rub` (прибавляется к вычету без множителя RWA), растущая часть роста вычетов и регуляторный вычет сценария — `deduction_pp` (п.п. RWA); высвобождение ОНА на стороне баланса — путь постоянной части прочих активов теми же рублями в том же квартале (лист сверяет равенство сумм обеих сторон); RWA модальной клетки в ключи не входят — неподвижной точки нет. Траектории — самые короткие, которые читатель ядра (М§0.4) прочтёт как ряд (ключи кварталов, ключи лет, интерполяция лет), со сверкой чтением ядра; год, который у варианта меняется внутри года, у центра — ключами кварталов (путь оси-связки); варианты — на ключах центра | `capital.reg_scenarios.<s>.deduction_rub.*` и `deduction_pp.*` по всем четырём сценариям, `volumes.other_assets_fixed_change`; концы связок на тех же ключах — оси роста вычетов и оси доли вычета якоря; траектории вариантов `k2_*`, `dta_release_*` (обе стороны), `reg_diverge_2028`, `ded_growth_all_*`, `ded_growth_asset_eta` / `ded_growth_asset_all` (природа роста вычетов на балансе) |
| | книга 0.4: слагаемого выпуска нет; ось доли вычета якоря ведёт и долю слагаемого роста вычетов (решение № 4, п. 3.3) — обе части пути вычета; вес приращения постоянной части прочих активов `capital.rwa.density.other_assets_fixed_change` = 0 пишет шаг `anchor` (суждение листа); λ_F и правило разброса цены — суждения шаблона, листом не выводятся | концы оси доли вычета якоря (ключи вычета обеих частей) |
| | книга 0.5 (решение № 5, п. 3.1): доля η роста вычетов 2026–2028 — и в пути постоянной части прочих активов той же суммой в том же квартале (вес 0, деньги из балансирующих статей); связки роста вычетов и доли η ведут обе стороны (путь постоянной части — пути связок); «регуляторный счёт» — вариант `ded_growth_regulatory`; сверка обеих сторон по слагаемым (1) и (4), знак суммы «постоянная часть + путь» (центр, концы связок, варианты) и ноль в квартале якоря; вычет «послабления» после возврата — смесь (п. 3.3), прежняя форма — вариант `relief_return_to_schedule` | путь постоянной части на концах обеих связок; траектории вариантов на ключах центра |
| `fees`, `opex` | комиссии и расходы к средним активам слоя «рыночные ставки как есть» на уровнях устава; кварталы года якоря — по фактам | `fees.growth_vs_wages`, `opex.real_growth` |
| `transmission` | решатель на концах осей цели передачи и уровня маржи | — (проверка осей) |
| `corridors` | коридоры гейтов по счёту ядра — правило для СВЕРКИ: команда сравнивает книгу с ним и не пишет (сторожа ставит сборщик рукой); правило «размах клеток центральной книги» читает клетки положительной вероятности (`model.grid.judged_cells`): у книги с четвёртым сценарием 12 клеток из 48 — нулевой вероятности, гейты их не судят; разрыв миров `roe_k_spread.max_world_gap` — мерой гейта `roe_k_homogeneity` (решение № 6, п. 2.4: среднее «ROE − k» клеток мира, которые судит гейт, с вероятностями аналитического слоя; прежняя мера — простое среднее — печатается рядом); расходы к доходам слоя печатаются против цели книги; пишется только поле окна фактов | сверка: `checks.wholesale_share`, `checks.pb_by_world`, `checks.terminal_share`, `checks.roe_k_spread`; запись: `checks.window_backtest.loans_share` |
| `ends` | концы осей, заданные результатом, и корни справочных вариантов | оси уровня расходов и комиссий, сезонного отношения расходов; варианты `fees_level_2026`, `opex_q4_whole_series`, связи с объёмом `fees_link_02`, `fees_link_10`, `opex_link_02`, `opex_link_10`, роста `closure_growth_stops`, `growth_stops_until_steps`, `growth_bank_forecast` |
| | книга 0.4: пара «комиссии и расходы на уровне 2026 года» (`fees_opex_level_2026`); цена развилок пути прочих доходов по мирам (`misc_forks`; вариантом книги не выражаются) | корни пары |

Шаги `near` … `opex` (с шагами `t2` и `deductions`) связаны и повторяются до сходимости (порог 1e-4, не больше восьми кругов); `transmission`,
`corridors` и `ends` считаются на записанных (округлённых) числах. Команда останавливается и ничего не пишет, если
подбор не сошёлся, невязка правила больше допуска, число вышло за коридор разумного или суждение, которое лист держит
константой, разошлось с книгой.

Числа книги ВТБ 0.3 выведены на форме С ДОКАПИТАЛИЗАЦИЕЙ и полом клетки (ключи `capital.recapitalization.*` и
`valuation.cell_floor` стоят в шаблоне). Пороги гейтов команда не пишет: расхождение книги с правилом листа — красный
флаг запуска и строка «осталось сделать руками».
